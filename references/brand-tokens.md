# 月明品牌令牌（唯一来源）

所有形态的颜色、字体、字号、圆角和动效缓动只从本文件取值。各 Skill 只写“用哪一组令牌、怎么排”，不再各自定义色值。工作区个人品牌网站的 `docs/brand-visual-system.md` 若与本文件不一致，以该文件为准并回写本文件，避免出现第二套。

依据：`moonlit-video-cover` 已确认的暖白 / 深蓝 / 铜橙品牌基准（2026-10）。旧的“深炭黑 + 科技绿”“深炭绿 + 亮绿”和动效语法初版的“深色网格 + 橙 #E8893A”统一并入本文件，旧色值只用于维护历史作品。

## 1. 两个主题，同一品牌

| 令牌 | 亮色 `paper`（封面、公众号、小红书、配图） | 深色 `night`（口播舞台、HTML 视频、数字人） |
| --- | --- | --- |
| `bg` 底色 | `#F6F2EA` 暖白纸感，可叠 32px / 1px / 3% 黑色细网格 | `#0E1A28` 深蓝夜，可叠 48px / 1px / 6% 暖白细网格 |
| `surface` 卡片 | `#FFFFFF`，1px `#E4DED3` 描边 | `#16263A`，1px `rgba(243,240,232,0.12)` 描边 |
| `ink` 主文字/标题 | `#182B42` 品牌深蓝 | `#F3F0E8` 暖白 |
| `ink-2` 次级文字 | `#394B60` | `#C9CFD8` |
| `muted` 说明 | `#536176` | `#8C99AA` |
| `accent` 唯一强调 | `#9B4F2C` 铜橙 | `#E0894F` 亮铜橙（深底上保证对比度） |
| `accent-soft` 强调底 | `rgba(155,79,44,0.10)` | `rgba(224,137,79,0.18)` |

规则：

- 一个画面只有一个 `accent`。铜橙只给本句正在说的关键词、关键数字或唯一结论，同屏不超过 2 处。
- 深色主题不是另一套品牌：同样的深蓝 + 暖白 + 铜橙，只是明暗互换。

## 2. 语义色（不是品牌色）

只在内容确实有这层含义时使用，一期内每种颜色只代表一类东西；同屏语义色最多 2 种。

| 令牌 | 色值 | 只表示 |
| --- | --- | --- |
| `ok` | `#3FAF7F` | 通过、成功、已验证、正确做法 |
| `warn` | `#D9534F` | 失败、风险、错误做法、被删掉的东西 |
| `info` | `#5B8CFF` | 第三方产品/平台（如飞书）、外部系统 |
| `alt` | `#3CB7A8` | 与主体并列的第二个概念（如 Skill 与 Agent 并列时的 Skill） |

绿色已从品牌主色降为 `ok` 语义色：不再用作标题、章节条、品牌线或大面积底色。

## 3. 字体

| 用途 | 字体 | 字重 |
| --- | --- | --- |
| 中文标题、大字、数字卡 | 思源黑体 / Noto Sans CJK SC | Black 900 或 Heavy 800 |
| 中文正文、标签、字幕 | 思源黑体 / Noto Sans CJK SC | Medium 500 / Bold 700 |
| 数字 | 同上 + `font-variant-numeric: tabular-nums`（滚动计数不抖） | 800–900 |
| 英文辅助行、英文标签 | Inter / Noto Sans | 500 |
| 代码、终端、文件名 | JetBrains Mono / Noto Sans Mono | 500 |

公众号排版沿用系统字体栈（PingFang SC 等），因为由微信渲染。

## 4. 字号阶梯

视频按 1920×1080 画布：

| 层级 | 字号 | 用途 |
| --- | --- | --- |
| `display` | 160–220px | 满屏大字（每 30–60 秒最多 1 次） |
| `number` | 120–160px | 数字揭示 |
| `title` | 64–80px | 场景标题、舞台页眉放大态 |
| `body` | 36–44px | 卡片正文、芯片 |
| `caption` | ≥ 28px | 说明文字；再小手机上读不清，宁可不放 |
| 中文字幕 | 由 talking-head 已确认字幕规范决定 | 本文件不覆盖用户确认的字幕层 |

封面按 25% 缩略图可读为准；公众号字号见 `moonlit-wechat-publisher/references/style-spec.md`。

## 5. 形状与质感

- 圆角：卡片 20–28px，芯片 12–16px，头像窗为圆形或 36px 圆角。
- 阴影：亮色 `0 12px 32px rgba(24,43,66,0.10)`；深色 `0 24px 64px rgba(0,0,0,0.45)`。
- 毛玻璃：仅深色主题叠在真人画面上时用，`backdrop-filter: blur(16px)`，底色 `rgba(14,26,40,0.78)`。
- 禁用：霓虹描边、发光线框、透视科技空间、通用机器人、扫描线、全屏绿/白闪。

## 6. 动效缓动（与动效语法一致）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `ease-out` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 元素入场 |
| `ease-in-out` | `cubic-bezier(0.65, 0, 0.35, 1)` | 舞台移动、真人缩放、卡片变形 |
| `spring` | damping 14–22 | 芯片、物件弹出 |
| 入场时长 | 0.2–0.3s | |
| 舞台移动 | 0.4–0.5s | |

## 7. 角色与人物

- 封面和视频里的“人”默认是本人真实形象（身份规则见 `moonlit-video-cover`）。
- 月明宇航员是插画系列角色：用于 `moonlit-astronaut-illustration` 线稿配图，以及用户本期明确要求的品牌叙事图；不再作为视频舞台、信息图或抽象概念镜头的默认主语。

## 8. 音效表（视频共用）

| 档位 | 声音 | 用在 | 参考响度 |
| --- | --- | --- | --- |
| 轻 | click / pop / tick | 元素入场、芯片落位、勾选 | 比人声低 18–22 dB |
| 中 | soft whoosh / swipe | 舞台平移、真人缩放、卡片变形 | 比人声低 14–18 dB |
| 重 | impact / hit | 满屏大字、章节核心结论 | 比人声低 8–12 dB，每 30–60 秒最多 1 次 |

音效提前画面约 0.04s 起；同一时刻只放一个档位。用户已确认的 SFX 必选层和具体素材以制作 Skill 的配置为准。
