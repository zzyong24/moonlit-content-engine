# 本期创意概念（母意象）

选题确认后、写稿前做。目的：让一期内容有一个**贯穿的画面概念**，脚本的比喻、封面的主画面、视频的舞台、配图的构图都从它出发，而不是各自临时找图。用户已给出口述时同样适用：概念只决定“怎么让人看见”，不改作者的观点和事实（见 `editorial-contract.md`）。

## 步骤

1. **写出本期一句话命题**（来自选题卡或作者原话）。
2. **提 3 个方向不同的概念**，每个只写两行：
   - 一句话概念：用一个画面讲清命题。
   - 关键画面：开场或高潮那一帧画面里有什么、发生什么变化。
3. 三个概念必须来自不同的类型：

| 类型 | 做法 | 例 |
| --- | --- | --- |
| 比喻 | 把抽象关系换成日常里看得见的东西 | “研发是一条流水线，我只是其中一个工位” |
| 实验 | 当场做一件事，让结果说话 | “同一个需求，分别丢给通用 Agent 和带上下文的系统” |
| 对比 | 两个状态并排，差异就是观点 | “十个产品摆一排，只有三个亮着” |
| 故事 | 一个具体的人、一个具体的时刻 | “过年，小外甥抱着手机和 AI 聊了一下午” |
| 数据 | 一个数字被放大到可感 | “654 亿 token 到底是多少” |

4. **按三问选一个**：
   - 能不能撑 60% 以上的段落（不是只用一次的点子）？
   - 封面能不能用它的一帧，缩到 25% 仍看得懂？
   - 材料能不能兑现（真实素材、可演示、可生成），不靠编造？
5. **写进 content_brief**：

```json
"creative_concept": {
  "statement": "十个产品只活下来三个",
  "type": "对比",
  "key_frame": "10 个方块一字排开，说到“两三个”时 7 个掉落、3 个亮起铜橙",
  "stage": "night",
  "reuse": {"script": "开场与第 2 章回扣", "cover": "主画面", "motion": "B-roll 类型 2", "illustration": "无"},
  "alternatives": ["…", "…"]
}
```

## 下游怎么用

- **脚本**（moonlit-video-script）：开场和至少一次章节回扣用这个意象；比喻词进入“触发词”列。
- **封面**（moonlit-video-cover）：`key_frame` 作为证据/关系板的首选画面。
- **视频**（talking-head / html-video / avatar）：舞台和 B-roll 类型从 `stage` 与 `key_frame` 出发；同一意象在片中变形推进，不每段换一套比喻。
- **配图**（material-illustration）：解释图沿用同一对象和颜色。

## 不做的

- 不为了意象改作者原意、虚构经历或数据。
- 一期只有一个母意象；局部比喻可以有，但不能与母意象打架。
